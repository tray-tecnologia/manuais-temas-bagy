# Localização na Plataforma

Um elemento que chama muita atenção nas lojas são os banners. Eles podem possuir diversões tamanhos e composições, mas agradam por trazer um trabalho gráfico mais elaborado. Este tema utiliza-os em posições estratégicas. Os banners podem ser cadastrados no painel administrativo acessando _**Marketing > Banners da Loja**._

Foram utilizados nesse tema as seguintes localizações:

* **Banners Home**: Representa os banners principais da loja. Utiliza a localização _**Banner Home**_ versão desktop e a localização _**Extra 1**_ para versão mobile.
* **Banners Grid (Mini Banners)**: São dois banners exibidos lado a lado. Utiliza a localização _**Extra 2**_ e _**Extra 3**_ para exibi-los. Estes banners são responsivos, desse modo, não contam com uma versão específica  para dispositivos móveis.
* **Banners Linha**: São banners que ocupam toda a largura do site. Utiliza a localização _**Extra 4**_ para a versão desktop e _**Extra 5**_ para versão mobile.
* **Banner Categoria:** São banners exibidos nas páginas de catálogo (categoria). Utiliza a localização _**Banner Títulos**_. Estes banners são responsivos, desse modo, não contam com uma versão específica  para dispositivos móveis.

::: info
**Vale lembrar que:** Vale lembrar que esses são os banners que foram utilizados nesse tema. Outras posições não são abrangidas pelo tema.

No momento do cadastro do Banner Home, pois é necessário marcar a opção Deseja cadastrar banner Javascript como **sim** para que mais do que um banner apareça na página inicial da loja. Você pode ter mais informações sobre o cadastro de banners clicando [**aqui**.](https://basedeconhecimento.tray.com.br/hc/pt-br/articles/6743567784603-Cadastrar-Banners)
:::

::: danger
### **Atenção**

Os banners precisam estar nomeados corretamente, caso contrário a plataforma não conseguirá reconhecer. Utilize [**essa ferramenta**](https://textedit.tools/slugify) para gerar nomes dos arquivos compatíveis com a plataforma.
:::
