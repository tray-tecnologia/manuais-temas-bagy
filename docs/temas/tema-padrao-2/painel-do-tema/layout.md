# Layout

A aba _**Layout**_ representa uma das mais importantes. Será através dela que você poderá controlar diversos comportamentos dos blocos do seu tema. Desenvolvemos opções claras para facilitar a utilização e dar bastante poder de personalização.

![](/tema-padrao-2/painel-tema-layout.png)
