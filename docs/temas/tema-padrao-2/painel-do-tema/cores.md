# Cores

A aba _**Cores**_ permite você personalizar várias variáveis de cores que controlam vários aspectos do seu tema, como cor dos títulos, cor do texto e muito mais. Você pode deixar o tema com a cara da sua empresa.&#x20;

::: tip
**Dica:** Caso queira fazer testes mas sem que isso reflita para os clientes da sua loja, basta duplicar e fazer as edições no tema duplicado.
:::

![](/tema-padrao-2/painel-tema-cores.avif)

As variáveis de cores são especificadas no formato hexadecimal, muito utilizado na internet. Você poder fornecer o código no campo, ou clicar na caixa ao lado do campo para abrir o seletor de cor. Ao clicar numa cor o seletor de cor irá preencher com o código hexadecimal equivalente a cor escolhida. A imagem abaixo da um exemplo desse processo.

![](/tema-padrao-2/painel-tema-cores-2.gif)

As cores são dividias em grupos menores para facilitar a organização e localização delas. Os grupos estão listados a seguir. Clique sobre cada um para visualizar as variáveis de cores pertencentes aquele grupo.
