# Dimensões

Os banners utilizados nesse tema possuem tamanhos diferentes dependendo da localização deles no tema. Para que as imagens fiquem legais e bem dispostas é necessário ficar atento as dimensões dessas imagens. Veja abaixo cada localização que utilizamos e a dimensão recomendada.

**Banner Home (Versão Desktop)** \
Localização: **Banner home**\
Dimensões do banner: **1920x576 pixels**

![](/tema-padrao-2/banners-dimensoes.avif)

**Banner Home (Versão Mobile)** \
Localização: **Extra 1**\
Dimensões do banner: **425x495 pixels**

![](/tema-padrao-2/banners-dimensoes-2.avif)

**Banners Grid\* (Mini Banners)**\
Localização: **Extra 2 e Extra 3**\
Dimensões do banner: **578x480 pixels**\
**\***&#x45;stes banners não possuem versões específicas para dispositivos móveis.

![](/tema-padrao-2/banners-dimensoes-3.avif)

**Banner Linha (Versão Desktop)**\
Localização: **Extra 4**\
Dimensões do banner: **1180x384 pixels**

![](/tema-padrao-2/banners-dimensoes-4.avif)

**Banner Linha (Versão Mobile)**\
Localização: **Extra 5**\
Dimensões do banner: **425x425 pixels**

![](/tema-padrao-2/banners-dimensoes-5.avif)



**Banner Categoria\*** \
Localização: **Banner Títulos**\
Dimensões do banner: **892x270 pixels**\
**\***&#x45;stes banners não possuem versões específicas para dispositivos móveis.

![](/tema-padrao-2/banners-dimensoes-6.avif)

**Banner Desconto Progressivo\*** \
Localização: **Cadastrado no menu de desconto progressivo**\
Dimensões do banner: **1180x112 pixels**\
**\***&#x45;stes banners não possuem versões específicas para dispositivos móveis.

![](/tema-padrao-2/banners-dimensoes-7.avif)

**Vale lembrar que:** Este banner não é cadastrado junto com os demais banners da loja, pois ele será vinculado exclusivamente aos produtos cadastrados no Desconto progressivo que deve ser configurado anteriormente, para que então seja associado um banner a promoção e exibido na página do produto.
