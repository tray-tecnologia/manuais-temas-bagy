# Redes Sociais

Configura os links e a visibilidade dos ícones de redes sociais no cabeçalho e no rodapé da loja.

* **Ocultar ícones de redes sociais no cabeçalho:** quando ativado, oculta os ícones de redes sociais exibidos no cabeçalho.
* **Ocultar ícones de redes sociais no rodapé:** quando ativado, oculta os ícones de redes sociais exibidos no rodapé.

## Links das redes sociais

Insira a URL completa do perfil em cada rede social para que o ícone correspondente seja exibido na loja:
