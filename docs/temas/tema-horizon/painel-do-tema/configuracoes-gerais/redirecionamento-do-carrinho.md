# Redirecionamento do carrinho

Configura o comportamento após clicar no botão de compra de um produto.

* **Redirecionamento do carrinho:** define para onde o cliente é direcionado ao clicar no botão de compra de um produto:
  * **Redirecionar para a página de produto** — o cliente é redirecionado para a página do produto após clicar no botão de compra
