# Popup de aviso

Configura um popup informativo exibido ao visitante ao acessar a loja. Útil para comunicados, avisos de restrição de idade ou promoções.

::: info
Para que o popup seja exibido, é necessário que tenha uma imagem ou uma mensagem configurada.
:::

* **Desativar popup de aviso:** quando ativado, o popup não é exibido na loja.

## Configurações do popup

* **Imagem:** define a imagem exibida no popup. Recomendado: 600x450px com até 250kb.
* **Exibir o aviso:** define a frequência de exibição:
  * **Ao abrir a loja** — exibe o popup em toda visita
  * **Apenas uma vez ao dia** — exibe o popup uma única vez por dia
* **Tempo para mostrar a janela:** define quando o popup aparece após o carregamento da página:
  * **Ao carregar a página**
  * **Após 5 segundos**
  * **Após 10 segundos**
  * **Após 15 segundos**
  * **Após 20 segundos**
* **Título da mensagem:** define o título exibido no popup. Ex: `Seja bem vindo!`
* **Mensagem:** define o texto principal do popup. Ex: `Para acessar esta loja, você precisa ter mais de 18 anos`
* **Texto do botão:** define o texto do botão de confirmação. Ex: `Ok, tenho mais de 18 anos`
* **Link do botão:** define a URL de destino ao clicar no botão. Ex: `https://google.com.br/`
* **Abrir link do botão em nova aba:** quando ativado, o link do botão abre em uma nova aba do navegador.
