# Notícias

Configura a exibição das imagens de notícias na página inicial e na página de listagem de notícias.

* **Altura da imagem do post (px):** define a altura das imagens exibidas nos posts de notícias. O valor deve estar entre 100 e 400 pixels (padrão: `160`).

::: info
Para cadastrar e gerenciar as notícias, acesse **Notícias da Loja** no painel administrativo.
:::
