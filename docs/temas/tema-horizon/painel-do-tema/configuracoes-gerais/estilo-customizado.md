# Estilo Customizado (CSS)

Permite adicionar CSS personalizado para estilizar elementos da loja além das opções disponíveis no painel do tema.

* **CSS customizado:** campo de código para inserir regras CSS. As alterações são aplicadas em toda a loja.

Ex:
```css
body {
  background-color: #000;
}
```

::: warning Atenção
Alterações incorretas no CSS podem afetar a aparência da loja. Recomendamos fazer testes no tema duplicado antes de publicar.
:::
