# Linha de Banners

Seção para exibir banners cadastrados no painel administrativo da loja, posicionados por slot. \
Cada bloco representa uma posição de banner. É possível adicionar até **4 blocos**.

::: info **Atenção**
Esta seção não suporta banner do tipo carrossel de imagens. \
Para configurar os banners, acesse o cadastro de banners no painel administrativo da loja em **Marketing > Engajamento > Banners**.
:::

## Blocos da seção

Cada bloco define uma posição de banner a ser exibida. É possível adicionar até **4 blocos**.

* **Posição do banner:** seleciona qual slot de banner será exibido neste bloco. As opções disponíveis são:
  * **Banner Home Desktop** — banner configurado para a posição home em desktop.
  * **Banner Home Mobile** — banner configurado para a posição home em mobile.
  * **Banner Rodapé** — banner configurado para o rodapé.
  * **Banner Inferior** — banner configurado para a posição inferior.
  * **Banner Lateral** — banner configurado para a posição lateral.
  * **Banner Títulos** — banner configurado para a posição de títulos.
  * **Banner Vitrine** — banner configurado para a posição de vitrine.
  * **Extra 1 a Extra 12** — banners adicionais configurados no painel administrativo, variando do 1 ao 12.

Os blocos podem ser reordenados para definir a sequência de exibição. \
Também podem ser ocultos ao clicar no ícone de olho.
