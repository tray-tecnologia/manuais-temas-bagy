# Full Banner

Para esse item é possível escolher se deseja exibir o banner ou não e escolher qual a posição dele.&#x20;

As posições recomendadas para esses banners são **Banner Home Desktop** e **Banner Home Mobile**.

::: info
**Vale lembrar que:** O cadastro dos banners é feito dentro do painel da plataforma, no menu de _**Marketing > Engajamento > Banners.**_ \
Algumas configurações de efeitos configuradas através da plataforma junto ao cadastro do banner não serão refletidas no tema.
:::
