# Barra de Informações Customizada

Para esse bloco é possível realizar algumas configurações a mais do que da Barra de Informações.

Todas as configurações possíveis são:

* Selecionar se deseja exibir os itens ou não através do clique no ícone de olho
* Selecionar o Tipo de ícone: Imagem ou Código SVG
* Inserir o ícone
* Inserir o titulo, a descrição e o link
* Arrastar os blocos para reposiciona-los
* Remover um item clicando no ícone da lixeira

![image](/tema-padrao-3/painel-tema-pagina-inicial-barra-informacoes-customizada.png)

Também é possível inserir um título e uma imagem de fundo para a seção. Essa imagem pode ser definida para exibir de maneira fixa de fundo.
