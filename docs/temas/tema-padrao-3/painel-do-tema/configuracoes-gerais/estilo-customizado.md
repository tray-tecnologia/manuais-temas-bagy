# Estilo Customizado

Neste item é possível inserir código personalizado de CSS que é aplicado em toda a loja. É útil para quem deseja alterar o estilo de algum elemento sem editar os arquivos do tema.

Você pode utilizá-lo, por exemplo, para:

* Ajustar tamanho ou cor de textos e títulos.
* Alterar espaçamentos (margens e paddings).
* Esconder ou destacar elementos específicos.
* Ajustar aparência de botões ou links.

::: info
**Importante**

Utilize esse campo se tiver conhecimento de CSS. Código inválido ou mal escrito pode alterar de maneira indevida a aparência da loja.
:::

::: info
**Dica**

Caso queira testar alterações sem que isso reflita para os clientes, duplique o tema e faça as edições no tema duplicado, ou saia da página sem salvar.
:::
