# Marcas

Para esse bloco é possível realizar algumas configurações, tais como:

* Selecionar se deseja exibir os itens ou não através do clique no ícone de olho
* Remover um item
* Arrastar o item para reposicioná-lo
* Selecionar a marca desejada
* Inserir uma imagem para a marca
* Selecionar se deseja exibir o link da marca
* Inserir o link desejado
* Selecionar se deseja abrir em nova aba


**Marca:** Exibe um select com as marcas cadastradas no painel da plataforma, em Produtos > Marcas e Fabricantes.

**Imagem da marca:** Possível cadastrar uma imagem para a marca e também removê-la caso não deseje mais exibir a imagem. Tamanho recomendado para a imagem é de 137x120 px.

**Exibir link da marca:** Selecionar se deseja exibir o link da marca. Lembrando que se essa opção não estiver selecionada, irá exibir a marca sem nenhum link.

**Link:** Inserir o link desejado. Se deixar em branco exibirá o link padrão da marca cadastrado no painel da plataforma, em Produtos > Marcas e Fabricantes.

**Abrir em nova aba:** Selecionar se deseja abrir o link em uma nova aba.

::: info Mais
Para cadastrar as marcas no painel da plataforma e ter o seu link acesse: **Produtos > Marcas**. Para maiores detalhes [clique aqui](https://basedeconhecimento.bagy.com.br/hc/pt-br/articles/44774623772180-Cadastrando-marcas-e-fabricantes-na-sua-loja-Bagy-3-0).
:::
