# Dimensões

Os banners utilizados nesse tema possuem tamanhos diferentes dependendo da localização deles no tema. Para que sejam exibidas boas imagens e fiquem bem dispostas é necessário ficar atento as dimensões dessas imagens. \
Veja abaixo as dimensões recomendadas.

::: info Observação:
Os banners podem sofrer redimensionamento das imagens em alguns dispositivos e dependendo do tamanho de tela de exibição.
:::


***

**Slideshow (Versão Desktop)** \
Dimensões do banner: **1920x600 pixels**

![image](/tema-horizon/banners-dimensoes.png)

**Slideshow (Versão Mobile)** \
Dimensões do banner: **600x700 pixels**

![image](/tema-horizon/banners-dimensoes-2.png)

***

**Linha de banners** \
Localização: **Extra1, Extra 2, Extra 3 e Extra 4** \
Dimensões do banner: **400x400 pixels** \
*Estes banners não possuem versões específicas para dispositivos móveis.

::: info **Lembrando que:**
Esses banners podem ser cadastrados no painel administrativo acessando _**Loja virtual > Banners da loja**_. \
Você pode escolher outras posições de banners para exibir em sua loja. O que está documentado aqui é a base que utilizamos caso queira se basear nela.
:::

![image](/tema-horizon/banners-dimensoes-3.png)

***

**Banners em grid** \
Dimensões do banner maior: **800x800 pixels** \
Dimensões dos demais banners: **700x373 pixels** \
*Estes banners não possuem versões específicas para dispositivos móveis.

![image](/tema-horizon/banners-dimensoes-4.png)
***

**Banner Categoria** \
Localização: **Banner Títulos** \
Dimensões do banner: **1920x270 pixels** \
*Estes banners não possuem versões específicas para dispositivos móveis.

![image](/tema-horizon/banners-dimensoes-5.png)

***

**Banner Desconto Progressivo** \
Localização: **Cadastrado no menu de desconto progressivo** \
Dimensões do banner: **1410x113 pixels** \
*Estes banners não possuem versões específicas para dispositivos móveis.

![image](/tema-horizon/banners-dimensoes-6.png)
